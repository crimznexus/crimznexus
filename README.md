## Projects

### Delphi: offline AI study assistant
*Python · ONNX Runtime GenAI · Phi-3.5 · Chroma · Qt*

A private, native Windows desktop app that turns course PDFs into a searchable knowledge base. Users ask questions and get answers grounded in the source material with page citations, and can generate quizzes. Inference runs locally on CPU with a quantized INT4 model and local embeddings, so no server, account, or API key is needed and documents never leave the device. Packaged as a per-user installer with automated test and release builds on GitHub Actions. *(Private repository.)*

### [NexusHost](https://github.com/crimznexus/NexusHost): game server hosting dashboard
*TypeScript · React · Node.js · Socket.io · Tailwind CSS*

A real-time dashboard for hosting and monitoring a game server on a remote machine. A Node.js hub brokers events between a headless Windows engine, which streams live CPU and RAM telemetry, and a React dashboard, which shows live gauges and sends remote commands. The engine also opens a public TCP tunnel so players can connect from outside the local network.

More work is in my [repositories](https://github.com/crimznexus?tab=repositories).
